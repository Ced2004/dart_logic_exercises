## Overview
This Dart console application evaluates student grades using structured logic. It combines functions, loops, conditional statements, and error handling (try/catch) to safely process inputs and evaluate performance.

## Key Features
- **Function:** `evaluateStudentPerformance()` handles logic and returns performance status.
- **Loop:** `for` loop iterates through grade records.
- **Error Handling:** `try/catch` block catches out-of-range grades and invalid string inputs.
- **Conditionals:** `if/else` checks if the average meets the passing mark (75.0).

## How to Run
1. Open [DartPad](https://dartpad.dev).
2. Copy and paste the contents of `bin/logic_exercises.dart`.
3. Click **Run**.
